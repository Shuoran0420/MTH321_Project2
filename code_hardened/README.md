# code_hardened —— 加固版求解器与独立验证

本目录是对 `code/` 的**加固副本 + 验证套件**，与仓库原有 `code/` **完全并存**，不替换、不覆盖任何原始文件。

原始 `code/` 保持提交 `74fff5e` 的状态不变。本目录自带依赖模块，可独立运行。

---

## 1. 与原模型的关系

**数学模型一行未改。** 以下全部保持原样：

| 组成 | 状态 |
|---|---|
| PDE：∇·(ε∇φ) = 0 | 未改 |
| 弱形式、P1 三节点三角形基函数 | 未改 |
| 边界条件（导体 Dirichlet，外边界零通量） | 未改 |
| 材料分区（εr = 4.4 / 1.0，按单元中心判定） | 未改 |
| 电容提取 C = 2U/V₀² | 未改 |
| M3–M7 冻结网格与自由度 | 未改 |

改的是**实现方式**（更快、更抗错）与**结论口径**（M7 的实际误差）。

数值等价性证据：在 M4–M7 上，加固版与原版的电容最大相对差 **4.2e-16**（见 `results/regression_check.json`）。

## 3. 快速开始

依赖与仓库 `requirements-adaptive.txt` 一致（numpy / scipy / scikit-fem / matplotlib）。

```bash
cd code_hardened

# 核心正确性审查（约 30 s）
python core_audit.py

# 与冻结电容表逐级比对
python regression_check.py

# 代数误差 vs 离散误差分离（level 5 约 1 min）
python solver_tolerance_sweep.py --level 5

# 独立 P2 参考解（较慢）
python reference_p2.py --element P2 --levels 4 5

# 角点分级加密
python graded_corner.py --base 5 --levels 7 --sigma 0.35

# 单元测试
pytest -q tests/
```

每个脚本都在自身目录插入 `sys.path`，无需设置 `PYTHONPATH`。

## 4. 主要结论

### 4.1 M7 的真实误差

用两条互不相干的路径确定参考值：

| 路径 | 外推值 (F/m) |
|---|---|
| P1 均匀族 Richardson 外推 | 1.2046688e-10 |
| scikit-fem P2 外推 | 1.2046659e-10 |
| **采用值** | **1.204666e-10** |

两者相对差 2.4e-6。据此：

| 网格 | DOF | C (F/m) | 相对误差 |
|---|---:|---|---:|
| M5 | 22 928 | 1.212253e-10 | +0.630% |
| M6 | 91 250 | 1.208074e-10 | +0.283% |
| M7 | 362 724 | 1.206198e-10 | **+0.127%** |

M6→M7 只变化 0.156%，看似收敛，实为误差减半。**M7 不是收敛值。**

### 4.2 收敛阶被角点奇异锁死

观测收敛阶：P1 = **1.155**，P2 = **1.145**。

两个多项式阶给出相同的阶，是奇点主导的典型签名。成因是迹线四个角点的 270° 介质楔形。因此单纯加密均匀网格收效有限（M8 预计仅到 0.057%）。

### 4.3 ε_eff 与 Z0 比 C 更准

比值抵消了共模偏差：

| 量 | 原报告值 | 修正值 | 误差 |
|---|---|---|---|
| ε_eff | 3.3535 | **3.3513** | 0.066% |
| Z0 | 50.642 Ω | **50.690 Ω** | 0.094% |

（C 本身误差 0.127%）

### 4.4 角点分级可恢复二阶收敛

在 M5 背景上对角点做几何分级：

| 方案 | DOF | 相对误差 |
|---|---:|---:|
| 均匀 M7 | 362 724 | 0.127% |
| 角点分级 | 139 426 | **0.0172%** |

精度提升 7.4 倍，自由度减少 62%。误差停滞值随背景网格 4 倍加密下降 4.02 / 3.89 倍，说明误差可分解为「角点奇异项 + 光滑区 h² 项」。

**注意**：这是同一连续问题在另一套网格上的离散结果，不是修改物理模型，也未替换 M7 的权威数值。

### 4.5 代数误差与离散误差的分离

level 5 上 CG 容差扫描：

| cg_rtol | C (F/m) | 代数误差 / 离散误差 |
|---|---|---|
| 1e-2 | 1.238227e-10 | 3.40 |
| 1e-4 | 1.212254e-10 | 1.10e-4 |
| 1e-6 | 1.212253e-10 | 6.68e-9 |
| 1e-8 | 1.212253e-10 | 6.43e-13 |
| 1e-10 | 1.212253e-10 | 0（双精度不可分辨） |

rtol ≤ 1e-10 后 C 与直接解完全一致，而该网格离散误差约 6.3e-3 —— 两者相差 13 个数量级，代数误差远非瓶颈。

## 6. 已知局限

- `corner_singularity.py` 的奇异指数拟合受 P1 质心梯度与各向异性网格影响，噪声较大，α ≈ 0.5 仅作**指示性**参考；真正可靠的判据是 P1/P2 同阶。
- 角点分级依赖 `radius0` 与 `sigma` 两个经验参数（本项目取 1.6e-4 m、0.35），未做系统敏感性分析。
- 参考值 1.204666e-10 的不确定度约 1e-5 相对量级，足以支撑 0.1% 级别的误差判断。
